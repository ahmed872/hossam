# 💌 دعوة زفاف حسام & ندى

دعوة زفاف رقمية فاخرة — تفتح كأنها جواب حقيقي بختم شمع، وبعدها تنقلك لموقع الدعوة الكامل.

**Crafted by [Weddify](https://portfolioweddify.vercel.app/)**

---

## ✨ المميزات

- 📩 **ظرف مختوم بشمع** يتفتح بأنيميشن 3D حقيقي عند الضغط على الختم
- 🌟 **بتلات ذهبية** متساقطة + زخة احتفالية عند فتح الدعوة
- ⏳ **عد تنازلي** بالأرقام العربية حتى لحظة الفرح
- 📍 زر **الوصول للقاعة** (Google Maps)
- 🗓 زر **ذكّرني بالمعاد** (يضيف الحدث على Google Calendar)
- 💌 زر **مشاركة الدعوة** (Web Share API / نسخ الرابط / واتساب)
- 🌹 **تخصيص اسم الضيف من الرابط** — أقوى ميزة للعملاء!
- 🎵 موسيقى خلفية اختيارية
- 📱 متجاوب بالكامل مع الموبايل + دعم `prefers-reduced-motion`

---

## 🖼 قبل النشر — خطوة واحدة مهمة

حط صورة العروسين (صورة الطفولة) في المسار ده بالظبط:

```
assets/couple.jpg
```

لو الصورة مش موجودة، الموقع هيعرض مكانها بشكل أنيق مع تنبيه — مش هيبوظ.

**اختياري:** حط ملف موسيقى هادية باسم `assets/music.mp3` وهتشتغل تلقائيًا مع فتح الظرف (مع زر كتم).

---

## 🌹 تخصيص اسم الضيف

ابعت لكل ضيف لينك باسمه وهيلاقي اسمه مكتوب على الجواب وجوا الدعوة:

```
https://your-site.vercel.app/?to=أحمد محمد
```

(المسافات تتكتب عادي — المتصفح بيظبطها لوحده)

---

## ⚙️ تعديل البيانات لعميل جديد

كل الإعدادات في أول ملف `js/main.js`:

```js
const CONFIG = {
  groom: "حسام",
  bride: "ندى",
  weddingDate: new Date("2026-07-29T20:00:00+03:00"),
  venueName: "...",
  mapsUrl: "...",
};
```

والنصوص نفسها (الأسماء، الآية، العناوين) في `index.html`.

## 🚀 النشر

الموقع static خالص — من غير build ولا dependencies:

- **Vercel:** اسحب الفولدر على vercel.com أو `vercel deploy`
- **GitHub Pages:** Settings → Pages → Deploy from branch

